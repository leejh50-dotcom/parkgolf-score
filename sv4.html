🎯 자동 조편성 시스템

접수된 명단으로 4명 1조 자동 배치
구글 시트에 Apps Script로 설치하세요

⚠️ 준비 사항
1. 구글 시트에 "접수명단" 시트 생성
2. 이름, 성별, 생년, 소속, 연락처 입력
3. 아래 Apps Script 코드 설치

📋 접수명단 시트 형식

No 이름 성별 생년 소속 연락처
1 김영일 남 1965 강원 속초 010-1234-5678
2 이동수 남 1970 강원 속초 010-2345-6789
... ... ... ... ... ...
✅ 사용 순서:
  1. 구글 시트에 "접수명단" 시트 생성
  2. 접수 명단 입력 (이름, 성별, 생년, 소속, 연락처)
  3. 확장 프로그램 → Apps Script
  4. 위 버튼으로 코드 복사 → 붙여넣기
  5. 저장 후 새로고침
  6. 상단 메뉴 "🎯 조편성" → "자동 조편성" 실행
  7. "조편성결과" 시트 자동 생성 확인
